## :question: What is this repository about?

This repository contains a Playwright + TypeScript UI automation framework with sample tests, page objects, reusable fixtures, and environment-specific configuration.

## Current project highlights

- Playwright test runner with TypeScript
- Page object pattern in `Pages/`
- Shared test fixtures in `fixture/`
- Environment config in `env/`
- HTML report generation with Playwright
- Browser storage state and auth setup support

## Prerequisites

Make sure the following are installed on your machine:

- Node.js
- npm

## Setup

1. Install dependencies:

```bash
npm install
```

2. Install Playwright browsers:

```bash
npx playwright install
```

3. Optional: create a root `.env` file for the `env_variable` project:

```env
PREPROD_URL=https://example.com
```

## Project structure

- `tests/` — test specifications such as `tests/orange.spec.ts`
- `Pages/` — page object classes and page-level helpers
- `fixture/` — custom fixtures and test setup helpers
- `modal/` — supporting model/helper classes such as login user models
- `test-data/` — test data and input sets
- `env/` — environment configuration modules
- `playwright.config.ts` — Playwright configuration, projects, and browser settings

## Playwright projects

The repository defines these Playwright projects:

- `demo` — Chrome desktop project using `env/demo.env.ts` and shared auth storage state
- `preprod` — Firefox desktop project using `env/preprod.env.ts`
- `env_variable` — Chrome desktop project using `PREPROD_URL` from a root `.env`
- `setup` — setup project for authentication and shared storage state
- `storageState` — Chrome desktop project using saved auth state from `playwright/.auth/auth.json`

## Run tests

Run the available npm scripts:

```bash
npm test
npm run test:headed
npm run test:debug
npm run test:report
```

Run a specific project or spec directly:

```bash
npx playwright test --project=demo
npx playwright test --project=preprod
npx playwright test --project=env_variable
npx playwright test tests/orange.spec.ts --project=demo
```

Debug tests interactively:

```bash
PWDEBUG=1 npx playwright test --project=demo
npx playwright test --project=demo --debug
```

## Notes

- `demo` uses base URL, username, and password from `env/demo.env.ts`.
- `preprod` uses `env/preprod.env.ts`.
- `env_variable` reads `PREPROD_URL` from a root `.env` file.
- HTML reports are generated by the default Playwright reporter and can be viewed with `npm run test:report`.
